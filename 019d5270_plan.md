Checkout & Order History Plan

1. Current State
- CartController handles add/update/remove and totals but no checkout or coupons; Cart view (Views/Cart/Index.cshtml) only has confirm/delete modals.
- OrderController/Views are placeholders; no persistence in Orders/OrderItems/Payments tables despite EF models.
- Coupons exist in DB but unused; profile data stored on User entity. Need payment modal, coupon validation, order history UI.

2. Backend Additions
- Extend Controllers/CartController.cs with helper `IsProfileComplete(User)` plus `[HttpGet] CheckProfileStatus` JSON endpoint; reuse for server-side guard inside checkout POST. (Critical file)
- Create Services/OrderService.cs handling checkout transaction: read user cart, compute subtotal/discount, create Order, related OrderItems, Payment, and set initial shipment status (enum covering packing/delivering/done). Register in Program.cs. (New file)
- Add Controllers/CheckoutController.cs (or extend cart) with endpoints: `ValidateCoupon(code)` returning percent/amount and validity flags; `SubmitPayment(CheckoutRequest)` verifying cart, coupon, payment method, invoking OrderService, clearing cart, and returning summary for UI success modal. Guard with antiforgery + [Authorize]. (Critical file)
- Build ViewModels: ViewModels/Cart/CheckoutViewModels.cs containing `CheckoutRequest`, `CheckoutResponse`, `CouponCheckResult`, `ProfileStatusViewModel`, `OrderHistoryItemViewModel`, `OrderDetailTimelineViewModel`. Include data annotations for card/promptpay fields. (New file)
- Update ViewModels/Cart/CartViewModels.cs totals to expose coupon + final amount placeholders; include PaymentOptions and default selection.
- Update Controllers/OrderController.cs to query `_context.Orders` with includes (OrderItems  ProductVariant  Product, Payment, Coupon) and map to new view models. Provide `/Order/DetailsData/{id}` returning detail view model for modal.
- Optionally add Shipments handling if table exists; otherwise store shipping status + timestamps on Order.

3. Database & Validation Logic
- Coupon validation rules: StartDate <= today <= EndDate, MinPurchase <= subtotal, EndDate stored in DB timezone; compute discountPercent and clamp final total >= 0. Recheck inside SubmitPayment transaction.
- Profile completeness: require Fullname, Email, Phone, Address trimmed non-empty.
- Payment method: CreditCard requires 16-digit number (no spaces), Thai month dropdown value, expiry >= current month/year, CVV 3 digits; PromptPay only confirm flag.
- After successful checkout: remove cart rows, update ProductVariant stock (currently adjusted when items added/removed) so no extra change needed.

4. UI/Frontend Updates
- Views/Cart/Index.cshtml: replace disabled pay button with active handler. Inject Bootstrap modal markup (two panes: Credit Card, PromptPay). Include coupon input area, totals summary, success/failure states. Provide slot for QR image `~/img/promtpay_thiraphat.jpg`.
- Add new JS (either inline or wwwroot/js/cart-checkout.js referenced via `asp-append-version`):
  a. `initProfileGuard` fetches `/Cart/CheckProfileStatus` before showing modal; if missing fields, show alert + link to Profile page.
  b. `couponManager` handles realtime input (debounced fetch to `/Checkout/ValidateCoupon?code=...&subtotal=...`), updates DOM labels and caches discount amount.
  c. `paymentController` collects card/promptpay inputs, runs client validation, and if valid posts to `/Checkout/SubmitPayment` with antiforgery token. Show spinner and disable buttons during request.
  d. Handle success -> display success modal content + CTA to History page; failure -> show error toast.
- Ensure summary area updates final price when coupon applied and never below 0.

5. Order History UI
- Views/Order/Index.cshtml: render header with counts (items shipping vs completed). For each order, card shows image, product summary, payment method, order date/time, status chip (packing/delivering/done). Buttons for `View Details` and maybe `Track Shipment`.
- Create partial `_OrderDetailsModal.cshtml` to show timeline (3 icons, highlight current step), product detail list, shipping address block, customer info (name/email/phone). Use Bootstrap icons `bi-bag`, `bi-truck`, `bi-check-circle`.
- Views/Order/Details.cshtml: reuse same view model to support direct navigation (non-modal fallback). Include coupon info and payment summary.
